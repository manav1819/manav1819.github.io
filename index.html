Featured Projects

Security Awareness Gamification Platform (SAGP) — Capstone, Project Lead

A Next.js/TypeScript/Supabase/Phaser.js platform that teaches phishing and vishing recognition through play instead of slide decks. Led backend architecture and RBAC across three role-based dashboards (superadmin, org admin, employee), built two original games — CyberCarnival (a 19-enemy-type threat hunt with tiered difficulty) and CyberForge — plus a cloud-persisted badge system and a behavioral risk-scoring engine. Deployed on Vercel with a custom domain. View Live →

UMPDP — Unified Multi-Modal Phishing Detection Pipeline — IEEE ICPCT 2025

Combined a DistilBERT email classifier with CatBoost-based URL analysis into a single phishing-detection pipeline, and presented the work at the IEEE International Conference on Power, Control and Technology (ICPCT 2025).

MCP STDIO Supply-Chain RCE Research — Group Capstone Research

Semester-long research project analyzing 2026 MCP STDIO supply-chain RCE vulnerabilities (CVE-2026-30615, CVE-2026-30623): CVSS v4.0 scoring, detection engineering mapped to MITRE ATT&CK/ATLAS, an original Sigma detection rule, STRIDE threat modeling across six trust boundaries in OWASP Threat Dragon, and our own Agent Trust Boundary Compromise Framework (ATBCF).

TraceLite — Personal / Open Source

An open-source Bitcoin fund-flow tracer, built after losing funds to a scam and wanting the tooling to exist. Deliberately non-attributional — it tracks where funds moved, not who owns the wallets. v1 covers UTXO-model traversal via free block-explorer APIs, depth-limited hops, fan-in/fan-out heuristics, graph visualization, and JSON/PDF reporting.

Home Lab SOC

Repurposed an old laptop into a Proxmox VE host running ELK and Wazuh for detection engineering practice, with Raspberry Pi sensors earmarked for a honeypot/IDS feed — a sandbox for building the muscle memory SOC work actually requires.

AES Encryption & Decryption Web Application

A full-stack Flask app implementing AES cipher operations by hand: real-time hex evaluation, custom round keys, matrix operations (S-box substitution, permutation), and polynomial arithmetic over GF(2^8) — built to make the cryptography behind CTF crypto challenges concrete. View Live Demo →
